How to read this report
These are direct DataForSEO Google organic results for the same English-language mobile Android searches and fixed city coordinates used previously. Current checks target organic positions 1–40. Prior coverage varies by observation; inspect each cell. Google sometimes returned fewer than ten organic listings, so NF does not mean an exact rank of 11 or worse. Returned counts are shown in each detail view. Rankings use organic position, excluding ads, Maps and Google Business Profiles. Each city represents one search point, not a neighborhood-wide grid. Positive position changes mean improvement. A newly appearing result is marked new. A missing result shows its previous rank (was #…) or NF before; no numeric change is invented. The top three are search results, which may include your own site, directories or informational pages. These data show visibility, not traffic, leads or why a ranking changed. Comparisons use matching keyword, coordinate, device, OS and language. Focused refreshes use the preceding saved observation; untouched keywords retain the original comparison. Icon Dumpsters is scored separately from external competitors using the same saved city/keyword searches. This view preserves actual observation dates.
Source: DataForSEO Google Organic SERP API · Result definitions · Raw organic records, timestamps and task IDs are included in the downloadable JSON.
